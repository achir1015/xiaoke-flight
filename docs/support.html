小柯機器人3D真實飛行｜技術支援

駕駛客機翱翔臺灣上空：起飛、降落、天氣與機上突發狀況，AI 小柯陪你飛。

回報問題或建議

請到 GitHub 問題回報頁 留言，說明你的裝置型號、系統版本與發生的狀況，我們會盡快回覆。

常見問題

  • 怎麼起飛？油門推到底，速度到約 145 節時把操縱桿往後拉。也可以按「自動駕駛」讓小柯幫你飛。
  • 畫面卡頓？到「設定」把畫面品質調成「低」，重新開啟遊戲。
  • 小柯聽不懂我的問題？小柯內建常用指令（聯絡塔台、最近機場、自動駕駛、地圖）。想要更多回答，可以在設定填入自己的 OpenAI 金鑰（選用）。
  • 沒有語音？確認手機沒有切到靜音，並在設定開啟語音朗讀。
